# Capgemini Exceller assessment framework

## Primary source

`Capgemini Exceller Assessment Framework V2 (1).ppsx`, supplied by the project owner and inspected on 11 October 2026. The deck is marked “Company Confidential © Capgemini 2026.”

## Confirmed assessment journey

The deck describes five stages: English Communication; Technical Module; Debugging Assessment; AI-assisted Coding; and Cognitive Assessment. It says that some rounds are eliminatory and a candidate must clear each required stage to progress. It also says assessments 2–5 are attempted in one sitting once elimination-round clearance permits it. Individual invitation and assessment-portal instructions should take precedence if they differ.

## Confirmed timings and composition

| Stage | Confirmed details |
| --- | --- |
| English Communication | Listening, Speaking, Reading, Writing. The deck gives no duration or question count. |
| Technical Module | Two MCQ sections, 20 questions each, about 45 minutes total. |
| Debugging | One question, about 20 minutes, C/C++/Java. Method: Review, Identify, Fix, Validate. |
| AI-assisted Coding | Step-by-step scaffolding. Evaluation: AI literacy, prompt quality, problem-solving, review & adapt. The deck does not specify timing or question count. |
| Cognitive | Motion 6 min; Grid 12 min; Logical Reasoning ~25 min; Behavioural 25 min. |

## Content boundaries

The deck confirms technical topics from AI foundations through responsible AI, programming logic, DSA, software-engineering fundamentals and modern engineering awareness. It names Trees, Graphs, 2D Dynamic Programming and Advanced DSA in debugging. It frames AI-assisted coding around candidate process, not only final code.

All platform questions remain original practice content. Motion Challenge and Grid Challenge appear as awareness-only items; the current scope does not reproduce proprietary cognitive games.
