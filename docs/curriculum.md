# Pro Mode curriculum

1. AI / ML / DL and evaluation
2. LLMs, tokens, embeddings, and attention
3. RAG, grounding, and security
4. Responsible AI, evaluation, and observability

The 30-day roadmap connects these guides to the existing practice inventory, labs, interview studio, and mock simulator. The 7- and 14-day options are persisted study horizons that prioritize P0 blocks.
