# Assessment pattern used by the simulator

The simulator is a learning approximation: 20 original AI questions + 20 original technical questions, with a default 45-minute timer adjustable from 40 to 50 minutes. It has no claim to reproduce Capgemini’s proprietary software, score calculation, question order, or exact item bank.

Potential later stages—debugging, AI-assisted coding, cognitive/behavioral modules, and interview—are surfaced as separate practice experiences because candidate reports vary by campus.
