# Question-bank blueprint

The local bank contains 452 typed, deterministic MCQs. Every item uses four options, a stable answer index, explanation, distractor explanations, topic metadata, provenance, difficulty, and verification flag; `scripts/validate-data.ts` checks the schema, duplicate IDs, duplicate statements, and challenge fixtures.

Pro Mode prioritizes scenario questions for AI and technical systems. It does not label original, reconstructed, or research-informed content as an authentic past question. Grading is deterministic and no AI request can alter an existing answer key.
